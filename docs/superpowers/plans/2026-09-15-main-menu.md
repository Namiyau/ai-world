# 主页面 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为当前 Babylon.js 无限世界增加可用、可键盘操作、具有低模湖岸风格的启动主页面，并提供单人游戏、多人占位页、设置和操作说明。

**Architecture:** 新增独立 `MainMenu` DOM 组件，由 `Game` 管理启动暂停状态和单人存档动作。主页面覆盖在已经加载但暂停的当前世界上，退出后恢复现有 HUD 与世界循环；设置通过独立 localStorage key 持久化，不触碰地形、水体和道路生成。

**Tech Stack:** TypeScript, Babylon.js, Vite, DOM/CSS, Playwright browser acceptance, Node `tsx --test`。

## Global Constraints

- 多人入口必须明确显示“即将推出”，不可伪造联网功能。
- 不修改地形、水体、道路、POI 和世界生成算法。
- 保持当前中文 HUD、低模自然世界和深青色视觉语言。
- 主菜单必须支持键盘焦点、窄屏布局和减少动态效果。
- 每个生产行为先写失败测试，再写最小实现。
