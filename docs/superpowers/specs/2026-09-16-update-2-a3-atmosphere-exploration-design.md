# 主世界更新 2-A3：氛围与探索节奏设计

## 目标

在不重构稳定的地形、水体裁剪、道路与 Chunk 流式加载核心的前提下，让无限主世界具备可感知的昼夜氛围、远景引导、环境叙事和“空旷—丰富—地标—空旷”的探索节奏。

## 边界

- 水面只修改材质表现：低幅顶点波、按现有 `waterDepth` 的颜色过渡、Fresnel 与天空色反射；绝不修改水面三角形、湖岸裁剪或水位。
- 昼夜系统只控制 `Atmosphere` 所拥有的天空、太阳、半球光、方向光和雾，不创建第二套光源。
- 音频提供无资产依赖的环境提示接口；浏览器没有可播放资源时不请求、不报错、不自动播放。
- 新地标和叙事场景均由已有 owner-chunk 生命周期创建和释放；自然细节继续使用共享 master mesh 的实例化。

## 架构

### 1. `ExplorationRhythm`

一个纯、确定性的宏观格点场。每个 320m 的世界格由 seed 和格坐标决定 `quiet`、`lush` 或 `landmark` 节奏，输出细节、资源、POI、地标四个密度系数。它不改变地形采样；所有消费者只用它决定是否在已有合法候选上生成内容。这样既不会产生 Chunk 边界不一致，也不会让低洼地或道路规则失效。

### 2. 水体与 Atmosphere

`WaterLayer` 继续以水平 `WATER_CONFIG.level` 建网格；水体 shader 从渐变的双向波计算近似法线，以低成本高光和 Fresnel 混入由 Atmosphere 提供的天空反射色。`Atmosphere` 保存单一 `timeOfDay`，按日间曲线更新太阳方向、强度、环境光、雾密度、天空色和太阳盘。水体每帧取得 Atmosphere 的反射色与主光方向。

### 3. 环境音接口

`AmbientSoundscape` 是纯状态机：输入玩家位置、TerrainSampler、水位和昼夜阶段，输出 `forestWind`、`birds`、`shoreWater`、`nightInsects` 等带混合权重的提示。WorldManager 可将该状态暴露给将来的音频播放器；当前不引入音频文件、网络请求或浏览器自动播放限制。

### 4. 地标与环境叙事

`LandmarkLayer` 在现有无线电塔、风车、巨石阵、巨树基础上加入山顶瞭望屋和远景大桥类型。候选仍先经过水面、坡度、高度与道路净空筛选。`PoiLayer` 保持已有人工场景规则，新增可复用的叙事组合：撞毁车辆及散落物资、猎人营地、废弃补给点。它们遵守 owner chunk 和地面附着规则。

### 5. 性能与卸载

自然散布由节奏系数减少候选，低成本装饰继续用实例；地标和 POI 只由其 owner chunk 创建，并由相同记录释放。远景地标保留低面数拼装、禁用拾取与碰撞。验收记录每个 Chunk 的实例和根 mesh 数量，保证 Reload 时确定性签名相同。

## 验收

- 不同水深可得到稳定的浅/深水颜色和可见但小于岸线安全范围的波动；水面位置、索引和顶点平面不变。
- 同一输入时间可重复生成相同光照/雾/天空状态；日夜的太阳高度与强度连续。
- 声景接口在森林、湖岸和夜间给出对应且确定的权重，不需要声音资产。
- 大范围扫描能找到新增地标与三类叙事场景；它们符合地形和 Chunk owner 规则。
- 相同 seed 下节奏场、细节、POI、资源和地标签名完全一致；Chunk 卸载后不残留 mesh 或实例。
- `npm test`、`npm run build` 与浏览器环境/POI/水体验收通过。
