# 主世界三类角色视觉风格设计

## 目标

为低模卡通开放世界经济冒险游戏建立可持续扩展的角色视觉基线，并在主世界出生区域加入一个易找到的“角色展示点”，让玩家可以直接观察玩家探索者、普通商人和荒野近战敌人三种基础角色。

## 统一风格

- Stylized low-poly：低面数、硬朗轮廓、少量大色块，带适度材质明暗但不写实。
- 比例略卡通化：头部约为标准人体的 1.16 倍、肩部略宽，保证远距离可读；躯干与四肢使用简单块面。
- 不使用二次元大眼、夸张表情或恐怖伤口。敌人只通过破旧布料、护具和姿态表达危险。
- 所有角色拆成可替换模块：头发、帽子、上装、下装、鞋靴、携带物、职业道具。部件挂载在稳定的节点命名空间下，未来可替换几何、材质或动画而不修改生成规则。

## 三个基础角色

### 玩家探索者

- 正面：橄榄绿实用夹克、暖棕腰包、深灰工装裤、棕色靴子；短发露出脸部轮廓。
- 侧面：背部略向后鼓出的小背包，腰包和靴底形成清晰的横向层次；手臂保持自然下垂，方便骨骼绑定。
- 背面：夹克后背有简化的浅色织带和背包主体，裤腿与靴子颜色分离，远处仍能识别。
- 配色：夹克 `#607f58`、背包 `#72583c`、工装裤 `#39484a`、靴子 `#2d2925`、皮肤 `#d6a27b`。

### 普通商人 NPC

- 正面：赭黄色短外套、米色衬衣、深棕长裤；宽檐帽和胸前小挂牌明确职业感。
- 侧面：一侧斜挎货包，手边可挂小账本或短木牌；轮廓比玩家更方正稳定。
- 背面：帽檐、外套下摆和货包形成三个清楚的背面层次，避免只换颜色造成职业不明显。
- 配色：外套 `#b98649`、衬衣 `#ded0ab`、裤子 `#55463b`、帽子 `#705238`、货包 `#8f6744`。

### 荒野近战敌人

- 正面：褪色红棕短外套、不对称护肩、灰色旧裤和厚靴；面部保持中性，不做恐怖化。
- 侧面：一侧手臂有旧护腕，腰侧挂短棒；身体轻微前倾，传达近战姿态。
- 背面：破旧披布或补丁布块和单侧背带打破对称，仍保持低面数可读。
- 配色：旧外套 `#89564b`、护具 `#625f58`、裤子 `#48474a`、靴子 `#312d2c`、布条 `#ad765d`。

## 场景展示

主世界出生区域固定生成一个小型木质展示台，三个角色并列摆放，分别配有中文名称牌。展示点不是 POI 候选，不参与经济或交互，不添加额外任务；其生命周期由 `WorldManager` 管理，只在主世界加载，位置贴合实际地形并避开水面。HUD 继续使用已有地标/坐标信息，额外提供“角色展示点”调试查询，便于验收。

## 运行时结构

- `CharacterCatalog.ts`：纯数据，定义角色身份、模块槽、比例、色板和正/侧/背面设计说明。
- `CharacterVisuals.ts`：Babylon 低模几何构造器。每个模块使用独立节点并共享材质缓存；三种角色只生成展示所需的少量网格。
- `CharacterShowcaseLayer.ts`：固定展示点、木台、名称牌与卸载逻辑；消费 `TerrainSampler` 取得地面高度。
- `PlayerAvatar.ts`：继续负责玩家逻辑锚点和网络快照；默认玩家外观与角色目录使用同一套数据。

## 测试与验收

- 纯数据测试：三种角色存在、模块槽完整、正/侧/背设计说明和颜色为确定值。
- 几何测试：每个角色生成节点数有限、组件带稳定模块名、展示台高度来自 terrain sampler，不出现 NaN。
- 确定性测试：相同 seed 与出生位置生成相同展示点位置和角色目录。
- 构建与浏览器截图验收：主菜单进入单人后，沿出生点附近可看到“角色展示点”；不检查不存在的网络功能。
