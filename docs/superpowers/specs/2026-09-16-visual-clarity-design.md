# 画面清晰度与视觉表现修复设计

## 目标

恢复浏览器原生清晰度，并在保持 stylized low-poly 风格的前提下改善雾、光影、太阳、湖面和人物轮廓。

## 已确认根因

- 默认 `balanced` 画质把硬件缩放设为 `1.25`，导致 `1440×900` CSS 画布只渲染 `1152×720` 后再放大。
- 当前雾密度约 `0.0081`，在 200m 级别已经几乎完全吞没远景；天空 shader 还叠加了偏重的地平线 haze。
- 太阳虽然是圆形球体，但远距离材质参与场景雾，实机不清晰且没有独立柔和光晕。
- 湖面岸边颜色从浅水到深水变化过硬，低振幅波纹缺少可读性。
- 角色使用 `CreatePolyhedron(type: 1)`，头部形成尖顶；整体局部模型高度约 3.6m。

## 方案

1. 画质：`balanced` 使用原生分辨率，`quality` 使用轻度超采样，`performance` 保留降采样选项。
2. 氛围：降低基础雾密度和天空 haze，保留远景层次但不覆盖近中景；降低环境光占比并提高太阳塑形能力。
3. 太阳：保持真实圆形低模球体，关闭太阳材质受雾影响，并加入低透明度、同位置的柔和光晕层。
4. 湖面：不改变水面几何拓扑；柔化浅水青色，增加两层低频微波和克制的天空反射，保证水面仍为不透明 stylized water。
5. 角色：改用圆润低模多面体头部，保留略大头比例；统一角色模型缩放至约 2.8–3.0m，脚底仍以展示台为基准。

## 验收

- 单元测试验证画质缩放映射、太阳材质不受雾、角色头部不是尖顶且高度受控。
- 浏览器验收读取真实引擎渲染尺寸、雾、灯光、太阳包围盒和水材质，并保存清晰度、太阳、水面、角色展示截图。
- `npm test`、`npm run build` 和浏览器验收均通过。
