# 显示分辨率、太阳与角色比例设计

## 目标

让 Esc 菜单可控制浏览器 3D 画布的内部渲染分辨率；用无光照、无黑芯的风格化日轮替换当前太阳球体；把展示角色调整到与第一人称眼高相符的约 1.60–1.70m。

## 已确认根因

- 当前 `renderQuality` 只是隐藏在“画质”中的硬件缩放映射，玩家无法明确选择或看到渲染分辨率。
- `sun-disc` 是 `StandardMaterial` 球体，且它的 `diffuseColor` 为黑色。核心球与透明光晕混合时会产生黑芯或脏边风险。
- 角色根缩放为 0.78，实测高度为 2.71–2.87m；玩家摄像机眼高约 1.72m。
- 日照的对比由方向光承担过多，低模大面会形成不自然的左右明暗断层。

## 方案

### 渲染分辨率

浏览器游戏不能修改操作系统或浏览器窗口的物理分辨率，因此 Esc 提供“渲染分辨率（相对窗口）”选项：75%、100%、125%、150%。它通过 Babylon 硬件缩放改变内部 render buffer，并实时显示实际像素宽高。旧存档的 `renderQuality` 映射为 75%、100%、125%，保证已有设置不丢失。

### 太阳与光照

太阳改为始终面向摄像机的正方形网格加程序化圆盘 shader：圆外 discard，圆内直接输出暖白到金色的径向色彩。它不使用 `StandardMaterial`、不受 fog、不开灯光、不开深度写入。保留独立的低成本透明光晕，并把环境填充提高、定向光对比适度收敛，使低模表面仍有方向感但不压黑。

### 角色比例

保留模块节点、坐标与低模头部形状，只将共享根缩放从 0.78 降至 0.46。三类角色的总高度应在 1.50–1.75m，使成年角色的头顶不再明显高过第一人称镜头。

## 验收

- Esc 能切换四档渲染分辨率，刷新后仍保存；100% 在 1440×900 窗口下产生 1440×900 内部画布。
- 太阳为相机朝向、无雾、无深度写入的 shader 日轮；不存在黑色 diffuse 材质路径。
- 角色均为 1.50–1.75m，头部保持圆润多面体和模块化结构。
- `npm test`、`npm run build` 和浏览器显示验收通过。
